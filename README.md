# aloomens.github.io

The website for Al Oomens' free audio plugins: <https://aloomens.github.io>

| Page | Product |
|---|---|
| [`/`](index.html) | Home: all three products |
| [`/open-vocal-studio/`](open-vocal-studio/index.html) | [Open Vocal Studio](https://github.com/aloomens/open-vocal-studio): lead-vocal channel |
| [`/clean-tone-studio/`](clean-tone-studio/index.html) | [Clean Tone Studio](https://github.com/aloomens/clean-tone-studio): clean guitar channel |
| [`/open-mastering-studio/`](open-mastering-studio/index.html) | [Open Mastering Studio](https://github.com/aloomens/open-mastering-studio): mastering chain |

Plain HTML and CSS (`assets/style.css`), no build step. GitHub Pages serves the `main` branch as it is (`.nojekyll` turns off Jekyll).

**Download buttons** point at each product's `releases/latest`, so they never need updating for a new version. **Screenshots** (`assets/img/`) are copies of each product's `docs/screenshot.png`; copy the new one here when a product's look changes.

To preview locally, open `index.html` in a browser.
